# PaqetFire v0.6.21

This release updates the bundled ProxiFyre engine to 2.6.1 and adds automated
compatibility checks against the actual bundled engines.

- Update ProxiFyre from 2.6.0 to 2.6.1 for reduced packet-checksum overhead and
  safer handling of invalid packet lengths and odd-length payloads. Upstream has
  not measured end-to-end throughput gains.
- Keep Xray-core 26.3.27, verified as the latest stable release on September 24,
  2026. Paqet remains at v1.0.0-alpha.21.
- Verify the new upstream archive and installed-file hashes and update the
  corresponding source notices.
- Add ten release-CI compatibility cases covering Xray routing policies and
  geographic data, LAN/hotspot listener configuration, and ProxiFyre application,
  protocol, address-family, exclusion, and TLS settings.

Existing profiles and connection behavior are preserved; no profile migration
or additional prerequisite installation is required by this engine update.

Local validation passed 173 tests, the desktop/broker builds, self-contained
publishes, MSI packaging, and the SOCKS password authentication smoke test.
Three administrator-only lifecycle tests were skipped locally. Live driver
capture, routed UDP, and kill-switch leak prevention were not revalidated by
these configuration checks.

The release includes the Windows x64 MSI installer and its SHA-256 checksum.
