# PaqetFire v0.6.24

This release adds a live session card to the Overview page while connected.

- See how long the route has been connected, the exit IP address and its
  country, download/upload rates with session totals, the active protocol
  (Paqet KCP mode and encryption), and the server endpoint.
- Track tunnel latency with a Good/Fair/Poor rating and a rolling ping-strength
  history. Latency is measured every few seconds over a warm connection
  through the Paqet SOCKS5 listener.
- Traffic totals and rates count only traffic routed through Paqet; direct and
  blocked destinations are excluded. Xray now enables its `StatsService` on
  loopback `127.0.0.1:10085` only, and `HandlerService` is not exposed.
- The exit country is resolved offline from the bundled `geoip.dat`, so the
  exit address is never sent to a geolocation service.

Upgrade the desktop and broker together using the MSI: this release uses IPC
version 11. After upgrading, disconnect and reconnect once so Xray picks up the
stats-enabled configuration. Engine and driver versions are unchanged.

Local validation: 208 tests passed with the staged engine payload, including
bundled Xray validation of the new configuration; three environment-dependent
tests were skipped. The release workflow also runs tests with the
staged payload before publishing.

The release includes the Windows x64 MSI installer and its SHA-256 checksum.
