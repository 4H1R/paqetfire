# PaqetFire v0.6.15

This release adds authenticated SOCKS5 sharing for Windows mobile hotspot clients,
with setup guides for v2rayNG and HAPP/Hiddify inside the app.

- Configure hotspot sharing independently of LAN sharing, using common proxy credentials.
- Confirm local network direct access when enabling hotspot sharing; invalid profiles are rejected by the broker.
- Detect active Windows Wi-Fi Direct or Hosted Network adapters on the supported default hotspot subnets. Inactive and unrelated adapters are rejected.
- Copy SOCKS URIs with correctly escaped credentials. Saved passwords remain protected: re-enter the proxy password on the Routing page to enable password and URI copying.
- Restore hotspot controls correctly when reopening the app, and include the guide resources in published installers.
- Validate broker configuration paths before creating missing directories.
- Remove the development planning folder under docs/superpowers.

Turn on Mobile hotspot in Windows Settings, then enable Hotspot SOCKS proxy in
PaqetFire, detect the address, and save the profile. A SOCKS-compatible client is
required; the phone's built-in Wi-Fi HTTP proxy setting is not supported.

The release includes the Windows x64 MSI installer and its SHA-256 checksum.
