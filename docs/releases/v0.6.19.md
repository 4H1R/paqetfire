# PaqetFire v0.6.19

This release adds verified in-app updates and makes upgrades safer when
PaqetFire or one of its managed engines is running.

- Check GitHub Releases automatically at startup or manually from Settings.
- Download the matching x64 MSI and verify its published SHA-256 checksum before
  launching Windows Installer.
- Show the installed version dynamically in the desktop UI and allow automatic
  update checks to be disabled.
- Close the desktop application during upgrades and uninstalls, and register
  managed engine processes with Windows Restart Manager.
- Stop Paqet, Xray, and ProxiFyre when the broker service shuts down so installer
  upgrades can replace their files cleanly.
- Centralize the application and installer version to prevent release artifact
  names from drifting out of sync with the tag.

The release includes the Windows x64 MSI installer and its SHA-256 checksum.
