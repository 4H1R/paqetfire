# PaqetFire v0.6.18

This release adds connection verification, network-aware automation, protected
multi-profile management, application discovery, and safer sharing tools.

- Verify the explicit PaqetFire proxy route over TCP/IPv4, routed UDP/DNS, and
  IPv6 while clearly distinguishing these checks from full leak testing.
- Automatically connect on unknown or route-required networks, select a saved
  profile per network, recover after network/resume events, and pause automation.
- Create, rename, duplicate, select, and delete machine-protected profiles with
  a default profile and redacted import/export.
- Find installed and running applications through a searchable routing picker,
  with warnings for selected executables that are missing or moved.
- Generate strong sharing passwords, test LAN/hotspot listeners, copy escaped
  URI/QR payloads, and copy redacted client setup bundles.
- Identify trusted networks using the active Windows connection profile and
  gateway signature, including safe behavior on ambiguous multihomed systems.

The release includes the Windows x64 MSI installer and its SHA-256 checksum.
