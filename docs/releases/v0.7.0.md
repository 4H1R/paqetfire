# PaqetFire v0.7.0

This release adds an optional exit proxy behind Paqet, Psiphon or your own
OpenVPN provider, and a Data usage page that shows how much went through your
Paqet server per profile and day.

## Exit proxy

- A profile can now leave the internet through a second network after the
  Paqet server, so destinations see that network's address and country instead
  of the server's. Choose it under **Routing → Exit proxy**; **None** keeps the
  earlier behavior, and profiles saved before this release keep it.
- **Psiphon** leaves in a chosen country, or the best one available. The
  desktop lists the countries Psiphon reports and shows the connected server's
  country. Psiphon relays TCP only, so UDP keeps leaving from the Paqet server.
- **OpenVPN** leaves through your own provider, such as Proton VPN, from an
  imported `.ovpn` file (TCP, embedded certificates). Routed TCP and UDP use
  it, and both fail closed when its tunnel is down.
- Both exits reach their own network only through Paqet's authenticated
  loopback SOCKS5 listener, so nothing routed to an exit leaves the computer
  directly. Every existing routing rule still applies first.
- Xray stays the only resolver. With an exit, its DNS-over-HTTPS queries leave
  through the exit too, so CDN answers match the place destinations see.
- Connect waits for the exit's tunnel; a route that asked for an exit never
  connects without it. An exit crash is repaired by restarting the transport.
- Live statistics count exit traffic and show the exit's public address and
  country. Diagnostics include the exit engine, its listener, its adapter, and
  its log with credentials removed.

### Getting the exit engines

Neither exit engine is part of the installer, which keeps the MSI small and
installs no extra drivers for people who never use an exit.

- **Download Psiphon** fetches the commit-pinned console client, through Paqet
  while connected and directly otherwise (never directly while the kill switch
  holds traffic). It is accepted only with its pinned size and SHA-256, which
  is checked again before every start. If the download is blocked, **Use a
  downloaded file** installs a copy fetched another way.
- **OpenVPN** uses your own OpenVPN Community 2.6 or newer from openvpn.net,
  accepted only from a folder that nobody but SYSTEM, Administrators, or
  TrustedInstaller can change, such as the default Program Files location.

### OpenVPN leaves the computer's networking alone

- OpenVPN gets a dedicated "PaqetFire Exit" adapter, created before Paqet
  starts. Pushed routes and DNS servers are refused; its only route is a
  lowest-priority default route on that adapter, so other applications and
  Paqet itself are unaffected. A route OpenVPN left behind after a crash is
  removed before the next start.
- An imported `.ovpn` is reduced to an allowlist of client options; scripts,
  plugins, management, file paths, routes, and DNS options never reach
  `openvpn.exe`.
- The `.ovpn` and password are DPAPI-protected and never sent to the desktop.
  Portable profile exports carry the `.ovpn` and username, not the password.

## Data usage

- The new **Data usage** page shows Today, This month, and Last 30 days
  totals with download and upload, and a daily list, for one profile or all of
  them. **Reset usage** clears the profile shown or every profile.
- Only traffic through Paqet, including an exit proxy behind it, is counted;
  directly routed and blocked traffic is not. These are the same counters the
  Overview session card uses.
- The broker records usage even while the desktop app is closed, including
  just before every disconnect, profile switch, and restart, so reconnects do
  not lose or double-count traffic.
- History is kept for 90 days in `%ProgramData%\PaqetFire\data-usage.json`,
  readable only by SYSTEM and Administrators. It holds profile IDs and byte
  counts, nothing about destinations.

Upgrade using the MSI. The desktop and broker use IPC v16 and must be upgraded
together, which the MSI does. Recording data usage starts with this version.

The release includes the Windows x64 MSI installer and its SHA-256 checksum.
