# PaqetFire v0.6.22

This hotfix restores connections broken by v0.6.21. That release bundled
ProxiFyre 2.6.1 correctly, but the broker's separate startup check still expected
the 2.6.0 executable hash. The broker rejected ProxiFyre and rolled back the
entire engine chain.

- Correct the broker's ProxiFyre startup hash and reported version to 2.6.1.
- Exercise the production startup check against the bundled executable and
  verify that corrupted executables are still rejected.
- Check all three production engine version/hash pins against the release
  manifest in ordinary CI, even without downloaded engine binaries.

Existing profiles and credentials are preserved. There is no need to reinstall
drivers or change routing settings. Xray and Paqet versions remain unchanged.

Local regression validation: 178 tests passed, with three existing
administrator-only lifecycle tests skipped. The regression test reproduced the
same ProxiFyre SHA-256 failure before the fix and passed afterward.

The release includes the Windows x64 MSI installer and its SHA-256 checksum.
