# PaqetFire v0.6.17

This release adds configurable destination bypass lists for traffic that should
use the normal connection instead of Paqet.

- Route domains and their subdomains directly with `example.com` or
  `*.example.com` entries.
- Route individual IPv4 or IPv6 addresses and CIDR ranges directly.
- Validate malformed domains, wildcards, addresses, and network prefixes before
  applying the routing policy.
- Give explicit custom routes priority over optional blocking and regional rules.
- Persist the direct-route list across restarts and show its entry count in the
  effective routing summary.
- Explain the hostname visibility limitation and when an IP or CIDR entry is
  needed for non-web protocols.

The release includes the Windows x64 MSI installer and its SHA-256 checksum.
