# PaqetFire v0.6.23

This release fixes profile management, makes profiles portable between PCs,
and adds advanced Paqet controls and factory reset.

- Select, edit, duplicate, or delete incomplete profiles while disconnected.
  Deleting the last profile opens a fresh empty profile. Each connection keeps
  its own transport key, and disconnected profiles can be saved without
  starting engines when the kill switch is off.
- Keep SOCKS sharing credentials consistent across all profiles. Importing,
  switching, or deleting profiles no longer changes the application's SOCKS
  username or password.
- Export transport keys with connection settings in the version 2 portable
  JSON format, grouped into `paqet`, `xray`, `proxiFyre`, and `sharing` sections.
  Existing version 1 redacted exports remain importable. Portable files contain
  secrets: keep them private and share only with trusted recipients. Adapter
  selection and SOCKS authentication remain local to the destination PC.
- Configure advanced packet and KCP options, including source ports, optional
  IPv6 capture settings, PCAP buffering, connection count, manual mode,
  encryption, MTU/windows, SMUX buffering/keepalive, and FEC. Validation now
  matches the bundled Paqet limits, and TCP flag cycles retain repeated flags
  and support the NS flag.
- Use **Settings → Factory reset** to disconnect, release the kill switch,
  remove saved profiles and credentials, clear generated engine configurations
  and backups, and restore app preferences and network automation defaults.

The profile lockout was caused by applying connection validation to profile
selection and deletion. The sharing-password prompt came from treating local
SOCKS authentication as profile-specific data during imports and switches.

Upgrade the desktop and broker together using the MSI: this release uses IPC
version 10. Engine and driver versions are unchanged. Existing saved profiles
are retained on upgrade; factory reset is an explicit, confirmed action.

Local validation: 184 tests passed; six tests requiring an elevated session or
staged engine payloads were skipped. The desktop build completed successfully.
The release workflow also runs tests with the staged payload before publishing.

The release includes the Windows x64 MSI installer and its SHA-256 checksum.
