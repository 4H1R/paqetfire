# PaqetFire v0.6.20

This release adds network interface selection and fixes stale router MAC addresses
after switching between a phone hotspot, Wi-Fi, and Ethernet.

- Choose Automatic or a specific active interface in the connection profile.
  Automatic prefers Ethernet, then Wi-Fi.
- Save the interface choice per profile and use it for the broker's connection.
  An unavailable selected interface reports an error instead of silently switching
  to a different connection.
- Keep Detect adapter details to refresh the available interfaces and router MAC.
  Failed detection clears the previous network's details and shows a warning.
- Resolve the router MAC using the selected interface's local IPv4 address, so
  another adapter's gateway entry is not used.
- Share adapter discovery between the desktop and broker, remove unused duplicate
  discovery code, and stop saving obsolete detected IP and MAC values.

Existing profiles continue to use Automatic. The picker lists active interfaces
with an IPv4 address and default gateway; disabled, disconnected, loopback, and
tunnel interfaces are excluded.

The release includes the Windows x64 MSI installer and its SHA-256 checksum.
