# PaqetFire v0.6.16

This release makes installation completion clear and ensures PaqetFire is easy
to find immediately after setup.

- Show a native setup wizard with an explicit completion screen and Finish button.
- Create a PaqetFire shortcut on the Desktop as well as in the Start Menu.
- Keep shortcuts managed by Windows Installer across repair, upgrade, and uninstall.
- Validate the completion dialog and Desktop shortcut contract in CI.

The release includes the Windows x64 MSI installer and its SHA-256 checksum.
