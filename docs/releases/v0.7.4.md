# PaqetFire v0.7.4

This release makes the desktop app safer to use while connected and easier
to follow: actions that would restart or drop the route now ask first, errors
say what to do, and every page has been reworked for clarity, screen readers,
small windows, and the light theme. Failed connects now explain why.

## Safer while connected

- **Switching profiles asks first when it would restart the route.** This
  covers the profile pickers on **Overview** and **Paqet connection**, the tray
  **Profiles** menu, **Duplicate** (the copy becomes active), and deleting the
  active profile, whose dialog now names the profile the route reconnects
  with.
- **Unsaved edits are no longer lost or skipped.** **Connect** on Overview and
  in the tray offers to save pending edits first instead of quietly connecting
  with the old settings. Exiting, and installing an update, offer Save, Discard,
  or Cancel.
- **Updates ask before dropping the route,** and the download can be
  cancelled.
- **Replace all profiles** on import shows how many profiles the file holds,
  is unavailable while connected, and needs a second confirmation. Export
  warns that the file holds transport keys before you choose where to save it.
- While the route is live, Save buttons read **Save and reconnect**.

## Overview

- The status card leads with the outcome, such as "Connected via France",
  instead of an engine count, and no longer repeats the routing scope three
  times. The large page header is gone, so the exit IP, speed, and latency sit
  higher.
- Errors have a title and the right severity, and name a next step with a
  button where there is one, such as **Open Services** when the PaqetFire
  service is not running.
- Disconnect is a plain button, so it no longer looks like Connect. Refresh is
  gone; F5 still refreshes.
- On first run, the setup checklist is the only call to action.
- The Paqet card names your server instead of the local SOCKS port, and the
  latency graph is labelled **Latency history**.

## Paqet connection

- Advanced transport settings explain themselves in plain words, keep numbers
  within their supported ranges, and say which values must match the server.
  KCP modes have descriptive labels. Choosing encryption **none** asks first.
- Profiles without a saved transport key are marked **· needs key**, and the
  transport key help text now says correctly that the key is stored encrypted
  on this PC.
- Editing a field clears only that field's error, and errors use the error
  colour.

## Routing

- The page is grouped into **Applications**, **Destinations & DNS**, **Exit
  proxy**, and **Sharing**. The selected-applications list sits under the
  routing mode that shows it, next to the protocol choices.
- Results of buttons such as **Test listener** or **Copy URI** appear next to
  the button instead of at the top of the page.
- **LAN share warns on networks you have not marked trusted,** and its switch
  says whether it is listening or waiting for a save. The Overview routing
  summary now includes sharing and the exit proxy.
- Protocol and kill switch options say what turning them off or on costs:
  unchecked protocols bypass PaqetFire, and the kill switch keeps routed
  applications offline after you disconnect.
- The OpenVPN 2.7 incompatibility is shown on the page instead of only in a
  tooltip, and the exit proxy state uses a coloured status.
- Application picker rows can be clicked to select them, are named for screen
  readers, and can be filtered.
- The v2rayNG and HAPP/Hiddify guides were corrected: they no longer claim the
  traffic is fully protected, lead with the QR code instead of sending the
  password-bearing link through other apps, mask the password, and number their
  steps consistently. Esc or Alt+Left leaves a guide.

## Diagnostics and Data usage

- **A healthy route now passes Verify route.** The capture process check is
  informational and no longer turns every result yellow.
- Failed checks are listed first, coloured by severity, and each says what to
  do next.
- **Save diagnostics…** writes the redacted report to a file, which is easier
  to send than clipboard text. The report starts with a summary and no longer
  repeats engine log lines.
- Missing required software moves to the top of Diagnostics, with download
  progress, a Cancel button, and a Restart now button when Windows needs one.
- Data usage can show the last 30 days, this month, last month, or the last
  90 days.
- Lists no longer rebuild every few seconds, so scroll position and screen
  reader focus stay put.

## Settings, accessibility, and appearance

- Settings is grouped into General, Network, Updates & data, Reset, and About,
  with plain descriptions under each switch. Factory reset is styled as a
  destructive action.
- The brand colours have light and high contrast variants and follow the
  Windows theme.
- The window sizes itself for the display's scaling, has a minimum size, and
  the Overview stacks its cards in narrow windows; the navigation pane
  collapses when space is short.
- Screen readers hear live values, such as the download rate, instead of only
  their labels, and verification and activity rows by their content. Page and
  section titles are headings, and Ctrl+1 to Ctrl+6 open the pages.
- The "still running in the notification area" notice appears once instead of
  every session, and the route-dropped notification no longer promises a
  reconnect when clicked.

## Connection failures

- A failed connect explains the cause instead of reporting only
  "EngineFailure". When Paqet or Xray is not ready in time, the message says
  whether the process ran, whether its port was listening and which program
  held it, and what the engine printed. Diagnostics name the program on each
  engine port and list recent failures and port moves.
- Downloaded routing data that Xray could not start with in time is skipped
  until the next routing data check, instead of costing every connect the same
  45-second wait.
- The Xray configuration no longer uses settings Xray 26 marks as deprecated.

## Engines

- Paqet `v1.0.0-alpha.21-a2`, Xray-core 26.10.31, ProxiFyre 2.6.4, and Windows
  Packet Filter 3.6.2 are unchanged.
