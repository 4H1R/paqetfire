# In-app Hotspot Client Setup Guides

We provide dedicated in-app step-by-step XAML guide pages for v2rayNG and HAPP/Hiddify with live session parameters and one-click copy buttons, rather than external documentation links or tiny disclaimer text.

Because mobile operating systems (Android/iOS) do not support SOCKS proxies in their native Wi-Fi settings, users must configure third-party SOCKS-capable client applications. Providing dedicated, visual in-app guides with live hotspot IP, port, and credential copy buttons eliminates setup errors and ensures critical steps (such as enabling Remote DNS) are clearly visible.
